# 本地文件转 PDF 工具设计

## 目标

提供一个 Windows 桌面软件，在文件不上传网络的前提下，将 TXT、DOC、DOCX 文件批量转换为 PDF，普通用户无需命令行操作。

## 首版范围

- 支持选择多个 `.txt`、`.doc`、`.docx` 文件。
- 支持选择输出目录，默认输出到源文件所在目录。
- TXT 直接生成 PDF，正确处理中文、空行、长行和分页。
- Word 文件优先调用 LibreOffice，其次调用 Microsoft Word；若均不可用，给出明确安装提示。
- 转换过程不覆盖已有 PDF，自动生成不冲突的文件名。
- 界面显示逐文件结果和成功/失败汇总。

## 非目标

- 首版不编辑 PDF，不提供 OCR，也不提供云端转换。
- 不承诺在没有 Word 或 LibreOffice 时还原 DOC/DOCX 的复杂排版。
- 首版不支持 Excel、PPT 和图片；这些留作后续扩展。

## 技术方案

采用 Python 3 + Tkinter 构建轻量 Windows 界面；使用 ReportLab 生成 TXT PDF；Word 转换通过外部办公套件的命令行/COM 能力完成。核心转换逻辑与界面分离，方便测试和后续增加格式。

考虑过 Electron（安装包较大）和 PySide6（界面更现代但运行时依赖显著更大）；首版选择 Tkinter，以更快获得小体积、可离线运行的可用版本。

## 约束与默认决定

- 所有转换仅在本机执行。
- 默认 A4、12pt、常规页边距；自动选择可显示中文的系统字体。
- 单个文件失败不影响队列中的其他文件。
- 后续可用 PyInstaller 打包为 `.exe`。
